# Aria to the Party — room upgrade

Upload `index.html` and the `assets` folder together to the root of the existing GitHub Pages repository.

Required structure:
- index.html
- assets/party-room.png

The existing supply rounds, counting, voice prompts, CSS-built dancers, dance animation, and generated disco music are retained. The finish screen now uses a full illustrated room background and separate inline SVG drawings for each collected balloon, cupcake, and party hat. These decorations are placed into the room dynamically; they are not an emoji list.

The game uses ordinary click events, which work for mouse and touchscreen taps in modern browsers. No external libraries or services are required.
